## 🚀 Projetos

### Mercado
Comparador de preços da feira do mês: monte a lista, digite os preços em até 6 mercados e veja onde a compra sai mais barata, inclusive entre embalagens de tamanhos diferentes (1 L contra 3 L, 200 g contra 800 g).

**Tecnologias:** Python · FastAPI · React (Vite) · MySQL

👉 [Ver o código e as telas](https://github.com/jonathankelvin1910-design/mercado)
